# Low Tide

An original interactive light study for a browser. Scroll from sundown to the first light of morning; drag or move across the sea to disturb its reflection. Single-page and dependency-free. Open `index.html` locally or put all three files at the root of a static host such as GitHub Pages.

No analytics, remote fonts, CDN, backend, account, cookies or network requests. Motion can be paused, and the initial state honors `prefers-reduced-motion`. The scene is a deterministic Canvas 2D painting, not a location or weather report.

## Controls
- Scroll to advance time.
- Move a pointer or drag a finger on the lower half to disturb the water.
- Pause motion with the top-right button. Keyboard and screen-reader accessible.
